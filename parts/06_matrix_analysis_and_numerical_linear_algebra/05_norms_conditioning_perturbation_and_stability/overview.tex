\section{Norms, Conditioning, Perturbation, and Stability}

% **Role:** quantitative matrix behavior and computation.
%
% Operator norms, Frobenius norm, singular values, condition numbers, norm inequalities,
% Gersgorin and Bauer--Fike bounds, interlacing, Weyl inequalities, pseudospectral intuition, and algorithmic stability.

Matrix norms measure stretch, energy, approximation quality, and sensitivity. Singular values organize norms, low-rank approximation, pseudoinverses, conditioning, and error bounds.

Perturbation theory studies how matrix information changes under small errors. Bauer--Fike, Gersgorin, interlacing, Weyl inequalities, and pseudospectra measure robustness.
