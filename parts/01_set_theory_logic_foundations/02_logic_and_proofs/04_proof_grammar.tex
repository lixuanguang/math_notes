\subsection{Proof Grammar}

\begin{proofmethod} \label{meth:proof-grammar} \hlt{Proof Grammar}\\
Given a mathematical claim, expose its proof obligations before selecting a proof rule.
\begin{enumerate}[label=(\roman*)]
\setlength{\itemsep}{0pt}
\item \hlt{Objects}: Identify the ambient sets or structures and declare the role of each symbol.
\item \hlt{Logical form}: Separate the hypotheses from the exact conclusion.
\item \hlt{Quantifiers}: Record the quantifiers in order. Note the permitted dependence of witnesses.\\
By Proposition \ref{prop:quantifier-order-can-change-truth-value}, quantifier order can change a statement's truth value.
\item \hlt{Well-formedness}: Verify that every expression has a defined meaning.\\
Check that every variable occurrence has unambiguous scope. Principle \ref{princ:well-formed-statements} records this requirement.
\end{enumerate}
A completed parse specifies the data, hypotheses, quantifier dependencies, and exact conclusion.\\
An undefined expression is ill formed rather than false and must be repaired before a proof begins.
\end{proofmethod}
