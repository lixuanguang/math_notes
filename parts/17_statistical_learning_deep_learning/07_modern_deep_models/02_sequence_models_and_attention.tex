\subsection{Sequence Models and Attention}

Sequence models process ordered data where context and position matter.

\begin{definition} \label{def:sl-recurrent-network} \hlt{Recurrent Neural Network}\\
A recurrent neural network updates a hidden state by
\[
h_t=\phi(W_xx_t+W_hh_{t-1}+b),
\]
then predicts from $h_t$.  Sharing $W_h$ across time lets the model process variable-length sequences.
\end{definition}

\begin{remark} \label{rem:sl-long-term-dependencies} \hlt{Long-Term Dependencies}\\
Repeated multiplication by transition Jacobians can cause gradients to vanish or explode.  Gated recurrent units, long short-term memory units, clipping, and skip-like paths mitigate this problem.
\end{remark}

\begin{definition} \label{def:sl-attention} \hlt{Attention}\\
Given queries $Q$, keys $K$, and values $V$, scaled dot-product attention has the form
\[
\operatorname{Attn}(Q,K,V)
=
\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V.
\]
It lets each position form a data-dependent weighted average of value vectors.
\end{definition}

\begin{remark} \label{rem:sl-attention-as-routing} \hlt{Attention as Routing}\\
Attention replaces a fixed local recurrence by content-dependent communication among tokens or locations.  Masks and positional encodings specify which interactions are allowed and how order is represented.
\end{remark}
