\subsection{Distributions and Sobolev Preview}

% **Role:** infinite-dimensional linear algebra powered by analysis.
%
% Test functions, distributions, weak derivatives, Sobolev spaces as bridge to PDE.

Distributions test against smooth compactly supported functions; Sobolev spaces package weak derivatives in normed or Hilbert spaces as a bridge to PDE.

\begin{definition} \label{def:test-functions-and-distributions} \hlt{Test Functions and Distributions}\\
Let $\Omega\subseteq\R^n$ be open. A \hlt{test function} is a smooth function $\varphi\in C_c^\infty(\Omega)$. A \hlt{distribution} on $\Omega$ is a continuous linear functional on the test-function space, written $u\in\mathcal{D}'(\Omega)$ and paired as $\langle u,\varphi\rangle$.
\end{definition}
