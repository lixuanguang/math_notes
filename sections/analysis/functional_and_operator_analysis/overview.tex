\subsection{Functional and Operator Analysis}

Functional and Operator Analysis treats infinite-dimensional linear algebra with analytic control. Normed and Banach spaces supply complete linear metric structure; Hilbert spaces add orthogonality and projection; the core theorems explain bounded operators and duality; weak topologies, compact operators, spectral theory, and distributions prepare the bridge to PDE and modern analysis.
